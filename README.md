**Project: # 🌱 PlantCare AI**

AI-powered plant disease detection using TensorFlow, FastAPI, React, and Gemini AI.

---

## 🌍 Live Demo

Frontend:
https://plant-care-ai-amber.vercel.app

Backend:
https://plantcare-ai-aiv5.onrender.com

---

## Features

- 🌿 Detect plant diseases from images
- 🤖 AI-powered treatment recommendations
- 📷 Camera support
- 🖼 Image upload
- 📚 Prediction history
- 💊 Treatment suggestions
- 🛡 Prevention tips
- ⚡ FastAPI backend
- 🎨 React + Tailwind frontend
- 🧠 TensorFlow MobileNetV2 model
- ✨ Gemini AI explanations

---

## Tech Stack

Frontend

- React
- Tailwind CSS
- Axios
- React Webcam

Backend

- FastAPI
- TensorFlow
- Pillow
- NumPy
- Gemini API

Deployment

- Vercel
- Render

## Dataset

PlantVillage

39 classes

MobileNetV2 Transfer Learning

## Model Performance

Accuracy: 93%
